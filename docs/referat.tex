\numberlesssection{РЕФЕРАТ}
Расчётно-пояснительная записка содержит \pageref{LastPage} страниц, \total{figures} рисунков, \total{tables} таблицы, \total{references} источников.

Ключевые слова: база данных, реляционная база данных, PostgreSQL,
Redis, кэширование, индексация, REST API, онлайн-заказ еды,
триггер, хранимая функция, ролевая модель.

Цель работы~--- проектирование и реализация базы данных для системы онлайн-заказа еды, а также приложения для доступа к ней.

В аналитическом разделе проведён анализ предметной области и
существующих систем онлайн-заказа еды, сформулированы требования
к разрабатываемой базе данных и приложению, выделены роли
пользователей системы.

В конструкторском разделе спроектирована база данных, описаны
ограничения целостности, разработаны алгоритмы хранимой функции
расчёта итоговой стоимости заказа и триггеров обновления рейтингов,
спроектирована ролевая модель на уровне базы данных.

В технологическом разделе обоснован выбор средств реализации,
реализованы база данных и приложение, описан интерфейс доступа
к базе данных.

В исследовательском разделе проведено исследование влияния
внешнего кэширования и индексации на время выполнения запросов
к базе данных.
